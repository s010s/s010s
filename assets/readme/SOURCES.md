# README asset sources

`museum-preview.webp` resizes and combines three reviewed collection thumbnails
from [`s010s/prehistoric-animal-museum`](https://github.com/s010s/prehistoric-animal-museum)
into one triptych. The component thumbnails are also preserved beside the
composite in this directory.

- `museum-sea-mosasaurus.webp` includes
  [“Mosasaurus”](https://sketchfab.com/3d-models/mosasaurus-fe0c25c4ed4e4d4aa05312121e2f68df)
  by Lukiethewesly13, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), modified for the
  Prehistoric Animal Museum, with project-generated scene art.
- `museum-land-stegosaurus.webp` includes
  [“PBR Stegasaurus (Animated)”](https://sketchfab.com/3d-models/pbr-stegasaurus-animated-ec254ea1554941fe8a131f62db0faf3d)
  by Ferocious Industries, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), modified for the
  Prehistoric Animal Museum, with project-generated scene art. The public-facing
  animal name is corrected to “Stegosaurus”.
- `museum-sky-tupandactylus.webp` includes
  [“Tupandactylus”](https://sketchfab.com/3d-models/tupandactylus-4ea8f4466c2c4e61bc57c12af296d43a)
  by Paleo Modelist (@victory_), licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), modified for the
  Prehistoric Animal Museum, with project-generated scene art.

The source repository records the complete provenance and modification notes in
its `THIRD_PARTY_NOTICES.md`.
